# Atelier Atlas project demo

[Download the narrated demo video](Atelier-Atlas-Demo.mp4)

105.6 seconds, 1920×1080, H.264 video and AAC audio. Captions are burned into the video; the SRT captions and narration script are also included.

The footage shows the real application running locally because the recording environment could not access the deployed site. It features https://atelieratlas.vercel.app/ . Pauses and navigation delays are shortened. Artist profiles and paintings are demonstration content, and the example upload uses a project sample painting. Contributions currently save in the browser. Spotify is shown as a playlist integration; successful Spotify audio playback is not demonstrated.

Synthetic narration uses Sherpa-ONNX and Piper en_US-ljspeech-high, trained on the public-domain [LJ Speech dataset](https://keithito.com/LJ-Speech-Dataset/). See Voice-Model-Card.txt. No third-party music is included.
